# Explainable AI Fraud Detection

A research-oriented fraud detection project covering data quality, baseline models, decision thresholds, explainability, robustness, probability calibration, temporal drift, performance monitoring, operational review capacity, and decision auditing.

## Project contents

- Stage 13 dashboard and analysis pages
- Aggregate model comparison, split summary, and threshold-selection tables
- Research results workbook and manifest

## Important limitations

Results depend on the dataset, split strategy, model assumptions, threshold policy, and quality of transaction identifiers. A repeated timestamp is not necessarily a duplicate transaction. Model metrics and explainability outputs alone do not establish production readiness or causal explanations.

Before reproducing or extending the work, review dataset provenance and licensing, privacy, possible leakage, reproducibility, and whether outputs contain transaction-level records.
