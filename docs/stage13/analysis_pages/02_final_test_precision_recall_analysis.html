Final Test Precision–Recall Operating Trade-off

Objective

Show how precision and recall trade off as the alert threshold changes.

Methodology

Sweep thresholds over the final test probabilities for visualization only.

Interpretation

The selected operating threshold was chosen on validation data. The test curve is descriptive and must not be used to retune the model.

Limitations

Changing thresholds changes alert volume and error costs; actual operational costs were not supplied.
