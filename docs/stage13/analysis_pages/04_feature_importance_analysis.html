Model-Specific Feature Importance

← Back to Stage 13 dashboard

Objective

Inspect which numeric inputs the fitted candidates rely on most.

Methodology

Random Forest impurity importance and absolute standardized Logistic Regression coefficients.

Interpretation

These are model-specific association summaries, not causal explanations. Compare rankings cautiously across model families.

Limitations

Correlated features can split or distort importance; coefficient magnitudes are not directly comparable to tree importance.
