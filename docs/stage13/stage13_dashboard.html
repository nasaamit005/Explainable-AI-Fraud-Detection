Stage 13 — Fraud Model Retraining Experiment

A chronological model-comparison experiment evaluating fraud detection performance, precision–recall trade-offs, classification errors, and model-specific feature importance.

Stage: 13 Features: 29 Split: Chronological 70/15/15 Evaluation: Imbalanced classification

Experiment overview

The experiment compares candidate fraud-detection models using a chronological training, validation, and final-test design. Validation data supports threshold selection; final-test metrics describe performance on the designated later period.

Observed result: Random Forest achieved the highest final-test average precision among the candidates in this experiment. Logistic Regression achieved a higher ROC-AUC. These metrics measure different aspects of ranking performance and should not be treated as interchangeable.

Important limitations and interpretation

  • Dataset provenance: Confirm the source, licence, permitted use, and appropriate attribution.
  • Temporal validity: Confirm timestamp semantics and ensure that feature values would actually have been available when each prediction was made.
  • Split boundaries: Check whether identical timestamps cross the training, validation, and final-test boundaries. If they do, assess whether a timestamp-grouped split is required and rerun the experiment if necessary.
  • Threshold selection: Choose operational thresholds using validation data and a documented decision criterion, not by repeatedly optimizing final-test results.
  • Metric interpretation: Precision, recall, average precision, ROC-AUC, calibration, and error counts answer different questions. No single metric establishes overall deployment readiness.
  • Feature importance: Importance scores are not causal evidence and may not explain an individual prediction.
  • Deployment: This is an experiment, not an approval to deploy a candidate model. Operational validation, privacy review, security checks, and monitoring remain necessary.

The reported ranking is descriptive of this experiment's observed results. Reusing the same final-test set to repeatedly select or tune models weakens its role as an independent evaluation set.
